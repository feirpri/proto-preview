`首页` · `建议` · `要闻` · `组合` · `对比` · `历史` · `设置`，另保留扩展 `popup`。

- **桌面**：左侧导航列出 7 页，当前页高亮，触控/点击目标高 44px。
- **移动端**：底部导航 5 项 `首页 / 建议 / 要闻 / 组合 / 更多`；「更多」打开底部抽屉，含 `对比 / 历史 / 设置`。全部页面 ≤2 次点击可达，当前页高亮；抽屉支持遮罩点击与 Esc 关闭，条目高 54px、关闭按钮 44×44px。

## 2.1 v7 增量：Token 门禁与全量实盘编辑

- **Token 门禁（全站）**：任何页面加载先校验 `localStorage` 中的 token；无有效 token 时只渲染 token 输入页，信息页 DOM 不渲染、布局隐藏。演示 token 为 `demo-2026`；输入错误就地提示，输入有效后写入 `localStorage` 并进入页面。顶栏「退出」清除 token 并重新拦截。页面明确标注「原型模拟门禁，真实 token 由服务端生成；静态站无法真正保密」。
- **全量实盘编辑（首页）**：新增「实盘数据编辑（演示）」区块，支持新增基金、编辑基金、删除基金；份额操作（购入/申购、赎回、清仓、加仓、减仓）；现金调整；总额校正。新增/编辑/删除按数据校正处理，不自动改变现金；份额操作按「金额 = 份额 × 当前净值」并同步现金。
- **份额优先**：份额输入自动折算金额，金额输入可反算份额（份额最多 6 位小数、金额 2 位小数）；展示份额、单位成本、当前净值、市值、当前/目标权重。
- **时间与前后对照**：每笔操作可选日期 + 时间；确认弹层展示受影响行的份额、单位成本、持仓市值、当前权重、目标权重、现金、总资产的前→后对照，并给出重算后最终现金/总资产/持仓。
- **历史重算**：生效时间早于已有记录时，按时间顺序插入并重算后续 N 条，弹层明确提示「将重算后续 N 条」；保存后提示重算条数。
- **校验**：份额 ≥ 0；赎回/减仓/清仓 ≤ 该时点持有份额；现金/总资产不为负；目标权重合计 ≤100%；基金代码 6 位数字且不可重复；份额 ≤6 位小数；金额 2 位小数；错误就地提示并禁用确认。
- **保存后同步**：基金表、权重、总资产、图表成本基线与本地审计同步更新；成功提示支持撤销上一笔；「恢复演示初始值」清空全部本地写入与 UI 状态。
- **本地审计**：记录生效时间、操作类型、基金、份额/市值前→后、现金/总额前→后、来源=网页；首页「演示写入与本地审计」展示最近记录。
- **显著标注**：所有页面顶部显示「演示写入 · 仅保存在本地，不影响实盘；Token 门禁为原型模拟，真实 token 由服务端生成」。

## 3. 页面结构

### 3.1 首页（`index.html`）

- **页头**：标题、说明、「本次更新 HH:MM:SS」、`estimate` 质量标记、手动刷新按钮、只读标识；移动端首屏可见。全页仅此一处刷新时间；顶栏只显示数据日期，不再重复时间。
- **大盘指数表**（4 项）：上证指数、深证成指、创业板指、沪深300。桌面列为「指数 / 点位（含涨跌点数）/ 涨跌幅 / PE-TTM / PE 历史分位（近 10 年）/ 状态」；分位数用细进度条 + 百分比呈现。桌面一条一行；移动端降级为堆叠行（名称与点位一行、涨跌幅与 PE 一行、PE 分位独占一行），不横向滚动。
  - PE-TTM 与历史分位数均为**演示值**，表头/脚注明确标注「近 10 年 · 演示」与「生产接入待数据调研确认」。
- **基金持仓表**（5 只）：列为「基金（chevron + 名称 + 代码）/ 当前持仓市值 / 当前权重 / 估算涨跌幅 / 今日预估收益 / 质量」。
  - 「估算净值」退出主列，「目标权重」移入展开区；展开区保留估算净值作为次要信息。
  - **数值单行（v6）**：「估算涨跌幅」「今日预估收益」不换行，右对齐、等宽数字（tabular-nums）、列宽稳定；金额带 `¥`（如 `+¥1,189`、`−¥259`）。`+12.34%`、`+¥123,456.78`、`−¥1,234.56` 等极端值在七档宽度均不折行、不溢出。
  - 桌面 1440/1280/1024：5 只基金在 900px 高首屏内可见，数值右对齐、等宽数字、行高紧凑。
  - 移动 390：基金名占整行；持仓市值 / 估算涨跌幅为主行，今日预估收益降级到次要行并保持数值单行；当前权重、目标权重、质量降级到基金名下方次要行，不横向滚动。
  - `stale` 基金（通信联接）行内标注最近可用 `13:58:20` 与延迟分钟数，不冒充实时。
  - 基金名称即展开/收起按钮：chevron 收起朝右、展开旋转 90°；维护 `aria-expanded` / `aria-controls`；支持鼠标、Enter/Space、Esc；同一时间最多展开一行。
  - 展开区包含：操作、金额、理由、执行状态、当前持仓市值、当前权重、组合目标权重、当前偏离、持仓成本净值、估算净值（次要）、今日预估收益；并提供「完整明细」链接到建议页锚点。
  - **调整后目标值（v6）**：展开区「仓位调整」显示「当前权重 → 目标权重」「当前持仓市值 → 调整后目标市值」「调整金额」「偏离（目标 − 当前，pp）」「执行状态」。`保持` 基金默认目标 = 当前、偏离 0；`减仓` 基金默认目标 = 当前 − 建议金额。计算口径按估算净值折算、目标市值保留两位小数，并在脚注注明。
  - **网页端模拟写入（v6）**：可输入目标权重（%）或调整金额（元），实时预览调整后目标值；校验非负、mock 可用现金/当前份额、5 只基金总权重 ≤100%、最小变动 ¥1,000，错误就地提示。保存后更新当前市值/权重、目标值与图表成本基线，显示成功提示与「撤销」，并记录本地审计（时间、基金、原值 → 新值、来源 = 网页）。状态写入 `localStorage`，刷新保持；提供「恢复此基金」与「恢复演示初始值」。显著标注 **「演示写入 · 仅保存在本地，不影响实盘」**，不新增下单能力。
  - 展开区趋势图：
    - **当日分时**：09:30–11:30、13:00–15:00 的估算涨跌幅折线，标出当前最后一点与时间；`stale` 基金止于最近可用时间。
    - **多周期趋势**：近一周 / 近一月 / 近一年 / 今年 / 近三年 / 近五年，segmented control 切换；净值为演示序列。
    - **今日估算**用主色 `#2563eb` 水平虚线；**持仓成本**用对比色 `#d97706` 水平虚线；曲线与持仓成本线的历史交叉位置用圆点 + 细竖线标记。
    - 图例区分「历史净值（实线）/ 今日估算（主色虚线）/ 持仓成本（对比色虚线）/ 历史交叉（圆点）」；SVG 带 `role="img"`、可读文本摘要与抽样数据表回退。
    - **每图放大（v6）**：当日分时与 6 个周期图均有「放大」入口（≥44px）。放大视图支持滚轮/双指缩放、拖拽平移、重置、`+`/`-` 与关闭；`Esc` 关闭；打开时焦点进入放大视图，关闭后回到触发按钮。放大后保留今日估算主色虚线、持仓成本对比色虚线、历史交叉点、图例、坐标轴与文本摘要；关闭后周期选择与页面滚动位置不变；仍为内联 SVG，不引入图表库。
    - 永赢高端装备（成立不足 5 年）的五年档改为 **「成立以来」** 并绘制可得区间（约 2.2 年演示数据），不再显示「近五年暂无数据」；生产可用性仍待数据调研确认。
    - 图表均标注「演示数据 · 生产接入待确认」，不声称已接入稳定接口。
  - 首页不再有「查看该基金建议」跳转链接；无 JS 时通过 `<noscript>` 静态快照保留核心持仓/估值数据。
- **数据口径说明**：首页唯一的 `official / estimate / partial / stale` 图例，持仓/PE/趋势图口径、刷新口径、演示写入口径、数据源、21:30 官方净值修正与风险提示。
- **演示写入与本地审计（v6）**：基金表下方展示「演示写入 · 仅保存在本地，不影响实盘」、已记录调整条数、审计列表（时间 / 基金 / 原值 → 新值 / 来源）与「恢复演示初始值」。
- **页脚**：首页不重复渲染全局页脚图例与风险声明；其他页面页脚保持原样。

### 3.2 建议（`advice.html`）

- 顶部：建议日期、整体决策摘要（市场状态「震荡」、一句话结论、目标权益仓位 72%、`executed · applied · 14:31` 状态与时间、审计保留说明）。
- 逐基金建议卡 ×5：基金名/代码、操作（保持 / 加仓 / 减仓）、金额（万元）、理由、`executed · 14:31 已应用`。
- 每卡附一行当前估值（净值 + 涨跌幅）与实际权重用于对照，标注数据时间；`stale` 基金使用最近可用时间。
- 明确「建议只读，执行仅通过 MCP 写入口」；建议页无下单/交易按钮、无输入框（网页端模拟写入仅存在于首页展开区，且只写 localStorage）。

### 3.3 要闻（`news.html`）

- 定位：可能影响经济与民生的政策、新闻与大事件；分类 `政策 / 民生 / 国际 / 行业`。
- 顶部显著标注 **「演示数据 · 非真实新闻」**，并说明「AI 每日 14:30 更新本次要闻；本页展示最近一次更新（截至 2026-11-10 14:30）的昨日/近期内容」。
- 10 条演示要闻，按时间倒序（11-10 → 11-06）；每条含日期、时间、分类、标题、1–2 句摘要、影响判断（利好/利空/中性）与受影响板块/主题、来源。
- 本期不实现刷新：无刷新按钮、无搜索/筛选交互，仅静态展示；页面注明「本期不提供刷新，后续迭代接入每日更新」。

### 3.4 组合 / 对比 / 历史 / 设置

- 保持 7 页导航与当前页高亮，内容沿用 v2：组合三组切换与偏离、对比三线与区间、历史时间线与交易、设置只读参数与开关展示。
- 设置页开关仍为静态示意，不响应点击；组合/对比/历史/设置页无写操作入口。首页仅新增本地演示写入，不涉及真实账本。

### 3.5 Chrome 扩展 popup（`popup.html`）

- 浏览器工具栏示意：扩展 icon + badge（显示上证涨跌幅）、omnibox `musi.local/home`。
- popup 内容：本次更新时间、4 个大盘指数（点位 + 涨跌%）、5 只基金估值摘要（净值 + 涨跌%），红涨绿跌。
- 入口：「打开首页」→ `index.html`，「查看建议」→ `advice.html`；badge/omnibox 仍仅示意。

| 份额操作 | 首页实盘数据编辑 | 购入/申购、赎回、清仓、加仓、减仓；份额 ↔ 金额双向折算；确认前展示前后对照 |
| 现金 / 总额校正 | 首页实盘数据编辑 | 现金增减或按目标总资产反推现金；现金为负时禁止保存 |

| 三组切换 | 组合页 tabs | 切换实盘 / AI 影子 / 基准 |
| 区间切换 | 对比页 tabs | 切换 22 / 66 / 244 / 380 个交易日 |
| 静态要闻 | 要闻页 | 无刷新、无搜索/筛选，仅浏览 |

除首页「仓位调整（演示）」外，所有交互均为只读导航/筛选/演示刷新。演示写入只修改浏览器 localStorage 并在页面内回显，不调用真实写接口、不写账本、不产生下单；真实执行仍通过 MCP 写入口。

## 6. Token 门禁与演示写入约束

- 真实账本仍只读：不接真实写接口、不写实盘/账本、不做真实下单、无买卖入口。
- **Token 门禁为原型模拟**：固定演示 token `demo-2026`，真实 token 应由服务端生成；静态站点无法真正保密，门禁只用于展示「无 token 不可访问」的交互与前端路由拦截，不构成真实安全边界，也不替代服务端鉴权。
- **演示写入**：首页实盘数据编辑只写浏览器 `localStorage`（操作记录键 `musi.v7.ops`，展开/周期/滚动键 `musi.v7.ui`），页面内回显，可撤销、可恢复初始值；不调用真实写接口、不写账本、不产生交易流水。
- 显著标注「演示写入 · 仅保存在本地，不影响实盘」与「原型模拟门禁，真实 token 由服务端生成」；成功提示与本地审计均注明来源「网页」。
- 其余页面（建议/要闻/组合/对比/历史/设置）无编辑表单、无交易按钮；设置页开关仍为静态展示，备份恢复为禁用样式。
- 页面文案明确「真实执行仍通过 MCP 写入口」「不构成投资建议/收益承诺」。

## 7. 已知简化点

1. **无后端/接口/SSE**：所有数据来自 `assets/data.js`，不接真实行情、净值、估值、PE 或分位 API。
2. **刷新为模拟**：进入页面与手动刷新只驱动加载态与模拟时钟（每次 +47s），不请求接口、不改变种子持仓；生产环境由估值接口返回。
3. **要闻为演示文本**：标题、摘要、影响判断与来源均为主观构造的演示内容，非真实新闻，也不代表真实政策或行情。
4. **图表为内联 SVG**：未引入 ECharts 或构建链；分时与多周期序列均为确定性生成的演示数据。
5. **PE / 历史分位为演示值**：未实现真实 PE 计算或分位服务；窗口写死近 10 年，生产接口、授权与稳定性待 HOM-57 调研结论。
6. **015790 成立以来区间**：永赢高端装备的五年档改为「成立以来」，用约 2.2 年的演示区间替代空态；真实成立日期与可得历史仍待生产数据确认。
7. **第二条横线口径**：本轮按「持仓成本净值」实现；若用户改为前高/支撑位等其他关键位，需要返工调整。
8. **持仓口径**：为保留 P1-2 种子持仓 52.9 万 + 现金 15 万，持仓金额展示 14:30 估算快照（执行前）；14:31 的执行明细在历史页交易记录中体现。
9. **AI 影子/基准为模拟**：不计费用、不涉及真实资金。
10. **扩展仅 popup 示意**：未打包 MV3 扩展，badge/omnibox 为静态示意，无真实轮询或快捷搜索。
11. **设置不可编辑**：未实现设置写入、备份恢复；token 仅在首页顶栏「退出」清除，未实现服务端签发/轮换/过期。
12. **数据时间固定**：默认演示时间为 2026-11-10 14:32:10；手动刷新仅在浏览器内递增模拟时间，刷新页面后回到固定值；展开行、趋势周期通过 `localStorage`（`musi.v7.ui`）保持，操作与审计通过 `musi.v7.ops` 保持，可「恢复演示初始值」。
13. **首页行内建议为演示**：展开区复用 mock 建议字段，不代表实时决策；完整执行仍以「建议」页与 MCP 写入口为准。
14. **网页端写入为本地模拟**：不调用后端、不写真实账本、不产生交易流水；份额/金额按当前净值折算，历史插入按本地操作序列重算，仅用于确认交互。新增/编辑/删除按数据校正处理，不自动改变现金，可再用现金/总额校正对齐。
15. **放大不引入图表库**：放大视图复用同一套内联 SVG，通过 CSS transform 缩放/平移；极大数据量与精细刻度仍待生产图表方案评估。

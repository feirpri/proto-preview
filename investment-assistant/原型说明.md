# 原型说明 · PWA 五页 + Chrome 扩展 popup

> 任务：HOM-40「P0 原型确认：PWA 五页 + Chrome 扩展 popup 静态原型与截图」
> 版本：原型 v1 · 2026-11-10
> 定位：**只读静态原型**，用于前端开发前的视觉与交互确认；不接真实 API、不写业务数据、不包含 Phase 3 生产代码。

## 2. 页面结构

### 2.1 今日（`index.html`）
- 顶部状态：数据时间 `2026-11-10 14:32:10`、`estimate` 质量标记、全局只读标识。
- 四张总览卡：市场状态（上证 3,628.41 / 创业板 2,431.20，关键位进度条）、总资产（67.9 万 = 持仓 52.9 万 + 现金 15 万）、今日预估收益（+3,201 元 / +0.47%）、权益仓位（77.9% vs 目标 72.0%，超配 5.9pct）。
- 今日建议横幅：`executed · 已执行`、执行时间 14:31、建议摘要、目标仓位说明。
- 逐基金操作卡：5 只基金，展示保持/加仓/减仓、金额、理由、权重与目标、执行状态 `executed`、估算质量；其中通信联接展示 `stale` 延迟标记。
- 数据说明卡 + 页脚质量图例：`official / estimate / partial / stale` 四类标记与风险提示。

### 2.2 组合（`portfolio.html`）
- 三组切换：实盘 / AI 影子 / 沪深300 基准，颜色分别为蓝 / 紫 / 琥珀。
- 组内总览：总资产、持仓市值 / 现金、今日预估收益、权益仓位 / 目标。
- 持仓与权重：5 只基金（基准组为沪深300 单行），实际权重、目标权重、偏离、今日预估；移动端自动转为卡片。
- 偏离提示：权益仓位超配、逐基金超配/低配、现金低配；基准组说明“无主动偏离”。
- 关键位：上证支撑/破位/压力、创业板支撑/压力。

### 2.3 对比（`compare.html`）
- 区间切换：近 1 月 / 近 3 月 / 近 1 年 / 全部；切换后曲线、图例、指标同步更新。
- 三线基点 100 曲线：实盘、AI 影子、沪深300 基准；内联 SVG，末端数值与图例一致。
- 指标卡：三组累计收益、AI 超额、AI 最大回撤。
- 指标明细表：累计收益、最大回撤、胜率、日均收益、超额收益（vs 沪深300）。
- 口径提示：三组互不写入、估算与官方分离、超额收益口径。

### 2.4 历史（`history.html`）
- 概览：最近 7 天建议、已执行、已回滚、最新官方修正（5/5）。
- 建议与快照时间线：每日建议、执行 `applied`、回滚 `reverted`、`estimate → official` / `estimate → partial` 修正标记、P1-2 种子基线。
- 交易记录：日期、基金、买入/卖出、金额、净值、执行/回滚状态、来源（建议/手动）。

### 2.5 设置（`settings.html`）
- 只读提示横幅：所有设置需通过 MCP 写入口修改，备份恢复在服务端执行。
- 关键位、目标权益仓位 72% / 现金 28%、5 只基金目标权重（16/16/22/8/10%）。
- 提醒开关（14:35 / 14:50 / 21:30）：静态展示，带“只读”标识，不响应点击。
- 数据源与 token 状态、SSE 状态、最近备份与备份恢复入口（禁用样式）。

### 2.6 Chrome 扩展 popup（`popup.html`）
- 浏览器工具栏示意：扩展 icon + badge `0.47%`、omnibox `musi.local/today`。
- popup 迷你总览：数据时间与 `estimate`、市场状态、三组今日收益、最新建议入口。
- badge / omnibox 仅示意，不包含真实扩展打包与轮询逻辑。

## 3. 关键交互

| 交互 | 位置 | 行为 |
|---|---|---|
| 页面跳转 | 左侧导航 / 底部导航 | 五页之间真实跳转，当前页高亮 |
| 三组切换 | 组合页 tabs | 切换实盘 / AI 影子 / 基准的统计卡、持仓表、偏离提示 |
| 区间切换 | 对比页 tabs | 切换 22 / 66 / 244 / 380 个交易日，曲线与指标同步重算 |
| 数据状态 | 全局顶栏 | 固定显示数据时间与 `estimate` 质量标记 |
| 质量图例 | 每页页脚 | 展示 `official / estimate / partial / stale` 与三组颜色 |
| 扩展入口 | popup CTA | 跳转 `index.html#今日`（本地原型页） |

所有交互均为只读导航/筛选；页面中没有下单、编辑实盘、写建议、修改设置等可操作入口。

## 5. 数据与视觉规范

- **种子基线**（P1-2，2026-11-05 收盘）：5 只基金；持仓 52.9 万 + 现金 15 万 = 67.9 万；目标权重 16% / 16% / 22% / 8% / 10%，合计 72%；沪深300 基准 67.9 万。
- **今日演示快照**：数据时间 2026-11-10 14:32:10；今日预估 +3,201 元（+0.47%）；权益仓位 77.9%。
- **三组颜色**：实盘 `#2563eb` / AI 影子 `#7c3aed` / 沪深300 基准 `#d97706`，在 tabs、图例、曲线、页脚保持一致。
- **质量标记**：`official` 绿、`estimate` 琥珀、`partial` 橙、`stale` 红；每页顶栏显示当前数据时间与 `estimate`，页脚展示完整图例。
- **涨跌颜色**：遵循 A 股习惯，红涨绿跌；金额均为演示数字。
- **响应式**：桌面 1440px 使用左侧导航；移动 390px 使用底部导航；页面无横向滚动，交互目标不小于 44px。

## 6. 只读约束

- 无 `<form>` / `<input>` / `<textarea>` / `<select>`，无下单、买卖、编辑实盘、写建议入口。
- 设置页开关为静态展示（`aria-hidden`、无点击行为），备份恢复入口为禁用样式。
- 页面文案明确“客户端只读”“需通过 MCP 写入口”“不构成投资建议/收益承诺”。
- 本原型不包含 Token 真实值；设置页 token 为掩码示意。

## 7. 已知简化点

1. **无后端/接口/SSE**：所有数据来自 `assets/data.js`，不接真实行情、净值、估值 API；SSE 状态仅展示。
2. **图表为内联 SVG**：未引入 ECharts 或构建链；曲线为确定性生成的演示序列，非真实行情。
3. **建议与持仓口径**：为保留 P1-2 种子持仓 52.9 万 + 现金 15 万，持仓金额展示 14:30 估算快照（执行前）；14:31 的执行明细在历史页交易记录中体现。
4. **AI 影子/基准为模拟**：不计费用、不涉及真实资金；AI 影子按目标权重演示，基准组按沪深300 全仓演示。
5. **扩展仅 popup 示意**：未打包 MV3 扩展，badge/omnibox 为静态示意，无真实轮询或快捷搜索。
6. **设置不可编辑**：未实现设置写入、备份恢复、token 管理；这些属于后续 MCP/服务端能力。
7. **PWA 安装/离线能力未包含**：未注册 Service Worker，仅做页面与响应式布局原型。
8. **CSV 导出未实现**：对比页只展示指标与曲线，导出入口留给 Phase 3 生产实现。
9. **数据时间固定**：截图与页面均使用固定的 2026-11-10 14:32:10 演示时间，不随时间变化。

## 8. 自检结果

- 五页 + 扩展 popup 共 **11 张 PNG**：桌面 1440px、移动 390px、扩展 420px（见 `screenshots/`）。
- 1440px 与 390px 两档均 **无横向溢出**（`screenshots/audit.json` 记录 `overflow=0px`）。
- 每页顶栏均显示数据时间与 `estimate` 标记；页脚均展示四类质量图例与风险提示。
- 三组颜色在 tabs、图例、曲线、页脚一致；组合/对比页切换正常。
- 全站交互元素仅导航与筛选 tabs；无写操作/交易入口（自动化检查：`input/textarea/select/form = 0`，交易类按钮 = 0）。
- 页面间导航、组合三组切换、对比四档区间切换均通过无头浏览器点击验证。
- 移动端底部导航固定，主内容预留安全间距；触控目标不小于 44px。

## 2. 信息架构（v5）

`首页` · `建议` · `要闻` · `组合` · `对比` · `历史` · `设置`，另保留扩展 `popup`。

- **桌面**：左侧导航列出 7 页，当前页高亮，触控/点击目标高 44px。
- **移动端**：底部导航 5 项 `首页 / 建议 / 要闻 / 组合 / 更多`；「更多」打开底部抽屉，含 `对比 / 历史 / 设置`。全部页面 ≤2 次点击可达，当前页高亮；抽屉支持遮罩点击与 Esc 关闭，条目高 54px、关闭按钮 44×44px。
- **跨页链接**：首页基金展开区「完整明细」→ `advice.html#fund-<code>`；建议页每张卡 → 回首页；导航文案与页面 `<h1>`、顶栏标题一致。
- 与 v4 的差异：首页信息优先级由「估算净值」改为「当前持仓市值 / 当前权重」；展开控件从行末按钮移到基金名称（前置 chevron）；指数表新增 PE-TTM 与近 10 年历史分位；基金展开区新增当日分时与 6 个周期趋势图；不改变七页导航结构、全局单一刷新时间与只读约束。

## 3. 页面结构

### 3.1 首页（`index.html`）

- **页头**：标题、说明、「本次更新 HH:MM:SS」、`estimate` 质量标记、手动刷新按钮、只读标识；移动端首屏可见。全页仅此一处刷新时间；顶栏只显示数据日期，不再重复时间。
- **大盘指数表**（4 项）：上证指数、深证成指、创业板指、沪深300。桌面列为「指数 / 点位（含涨跌点数）/ 涨跌幅 / PE-TTM / PE 历史分位（近 10 年）/ 状态」；分位数用细进度条 + 百分比呈现。桌面一条一行；移动端降级为堆叠行（名称与点位一行、涨跌幅与 PE 一行、PE 分位独占一行），不横向滚动。
  - PE-TTM 与历史分位数均为**演示值**，表头/脚注明确标注「近 10 年 · 演示」与「生产接入待数据调研确认」。
- **基金持仓表**（5 只）：列为「基金（chevron + 名称 + 代码）/ 当前持仓市值 / 当前权重 / 估算涨跌幅 / 今日预估收益 / 质量」。
  - 「估算净值」退出主列，「目标权重」移入展开区；展开区保留估算净值作为次要信息。
  - 桌面 1440/1280/1024：5 只基金在 900px 高首屏内可见，数值右对齐、等宽数字、行高紧凑。
  - 移动 390：基金名占整行，持仓市值 / 涨跌幅 / 今日预估收益为主行；当前权重、目标权重、质量降级到基金名下方次要行，不横向滚动。
  - `stale` 基金（通信联接）行内标注最近可用 `13:58:20` 与延迟分钟数，不冒充实时。
  - 基金名称即展开/收起按钮：chevron 收起朝右、展开旋转 90°；维护 `aria-expanded` / `aria-controls`；支持鼠标、Enter/Space、Esc；同一时间最多展开一行。
  - 展开区包含：操作、金额、理由、执行状态、当前持仓市值、当前权重、目标权重、偏离、持仓成本净值、估算净值（次要）、今日预估收益；并提供「完整明细」链接到建议页锚点。
  - 展开区趋势图：
    - **当日分时**：09:30–11:30、13:00–15:00 的估算涨跌幅折线，标出当前最后一点与时间；`stale` 基金止于最近可用时间。
    - **多周期趋势**：近一周 / 近一月 / 近一年 / 今年 / 近三年 / 近五年，segmented control 切换；净值为演示序列。
    - **今日估算**用主色 `#2563eb` 水平虚线；**持仓成本**用对比色 `#d97706` 水平虚线；曲线与持仓成本线的历史交叉位置用圆点 + 细竖线标记。
    - 图例区分「历史净值（实线）/ 今日估算（主色虚线）/ 持仓成本（对比色虚线）/ 历史交叉（圆点）」；SVG 带 `role="img"`、可读文本摘要与抽样数据表回退。
    - 永赢高端装备（成立不足 5 年）的「近五年」显示明确空态说明，代表生产可能存在的历史覆盖缺口。
    - 图表均标注「演示数据 · 生产接入待确认」，不声称已接入稳定接口。
  - 首页不再有「查看该基金建议」跳转链接；无 JS 时通过 `<noscript>` 静态快照保留核心持仓/估值数据。
- **数据口径说明**：首页唯一的 `official / estimate / partial / stale` 图例，持仓/PE/趋势图口径、刷新口径、数据源、21:30 官方净值修正与风险提示。
- **页脚**：首页不重复渲染全局页脚图例与风险声明；其他页面页脚保持原样。

### 3.2 建议（`advice.html`）

- 顶部：建议日期、整体决策摘要（市场状态「震荡」、一句话结论、目标权益仓位 72%、`executed · applied · 14:31` 状态与时间、审计保留说明）。
- 逐基金建议卡 ×5：基金名/代码、操作（保持 / 加仓 / 减仓）、金额（万元）、理由、`executed · 14:31 已应用`。
- 每卡附一行当前估值（净值 + 涨跌幅）与实际权重用于对照，标注数据时间；`stale` 基金使用最近可用时间。
- 明确「建议只读，执行仅通过 MCP 写入口」；无下单/交易按钮、无输入框。

### 3.3 要闻（`news.html`）

- 定位：可能影响经济与民生的政策、新闻与大事件；分类 `政策 / 民生 / 国际 / 行业`。
- 顶部显著标注 **「演示数据 · 非真实新闻」**，并说明「AI 每日 14:30 更新本次要闻；本页展示最近一次更新（截至 2026-11-10 14:30）的昨日/近期内容」。
- 10 条演示要闻，按时间倒序（11-10 → 11-06）；每条含日期、时间、分类、标题、1–2 句摘要、影响判断（利好/利空/中性）与受影响板块/主题、来源。
- 本期不实现刷新：无刷新按钮、无搜索/筛选交互，仅静态展示；页面注明「本期不提供刷新，后续迭代接入每日更新」。

### 3.4 组合 / 对比 / 历史 / 设置

- 保持 7 页导航与当前页高亮，内容沿用 v2：组合三组切换与偏离、对比三线与区间、历史时间线与交易、设置只读参数与开关展示。
- 设置页开关仍为静态示意，不响应点击；全站无写操作入口。

### 3.5 Chrome 扩展 popup（`popup.html`）

- 浏览器工具栏示意：扩展 icon + badge（显示上证涨跌幅）、omnibox `musi.local/home`。
- popup 内容：本次更新时间、4 个大盘指数（点位 + 涨跌%）、5 只基金估值摘要（净值 + 涨跌%），红涨绿跌。
- 入口：「打开首页」→ `index.html`，「查看建议」→ `advice.html`；badge/omnibox 仍仅示意。

## 4. 关键交互

| 交互 | 位置 | 行为 |
|---|---|---|
| 页面跳转 | 左侧导航 / 底部导航 | 7 页真实跳转，当前页高亮 |
| 更多抽屉 | 移动端底部「更多」 | 打开含对比/历史/设置的底部抽屉；遮罩/关闭按钮/Esc 关闭 |
| 自动刷新 | 首页进入 | 触发一次模拟刷新，按钮进入「刷新中…」态并显示加载样式，约 0.4s 后落定并显示页头「本次更新 14:32:10」 |
| 手动刷新 | 首页「刷新估值」 | 真实可点击（≥44px）；刷新中禁用并旋转图标；完成后更新页头时间（如 14:32:10 → 14:32:57），保持展开行、图表周期与滚动位置，不改变布局高度 |
| 基金展开/收起 | 首页基金名称（chevron） | 点击名称展开/收起；chevron 旋转 90°；同一时间最多一行；Enter/Space 可用，`aria-expanded` / `aria-controls` 正确；Esc 收起并回焦基金名称按钮 |
| 趋势周期切换 | 展开区 segmented control | 切换近一周/近一月/近一年/今年/近三年/近五年；当前周期 `aria-selected`，刷新与重载后保持 |
| 数据表回退 | 展开区「查看数据表」 | 展开抽样净值表（含日期、净值、区间与交叉说明） |
| 展开 → 完整明细 | 展开区「完整明细」 | 跳转 `advice.html#fund-<code>`，建议卡锚点顶部留白 |
| 建议 → 首页 | 建议卡「回首页看估值」 | 返回首页 |
| 三组切换 | 组合页 tabs | 切换实盘 / AI 影子 / 基准 |
| 区间切换 | 对比页 tabs | 切换 22 / 66 / 244 / 380 个交易日 |
| 静态要闻 | 要闻页 | 无刷新、无搜索/筛选，仅浏览 |

所有交互均为只读导航/筛选/演示刷新；除首页刷新按钮外无输入、下单、编辑、写建议入口。

- **今日演示快照**：数据日期 2026-11-10；盘中估值时间 14:32:10（模拟）；今日预估 +3,201 元（+0.47%）；权益仓位 77.9%。
- **当前持仓（v5 主列）**：财通 14.5 万 / 21.4%、机器人 13.9 万 / 20.5%、国联安 10.4 万 / 15.3%、通信 7.1 万 / 10.5%、永赢 7.0 万 / 10.3%；目标权重与偏离见展开区。
- **指数演示值**：上证 3,628.41（+0.42% / +15.21 点 / PE-TTM 15.82 / 分位 61%）、深证成指 11,452.68（+0.65% / +73.96 点 / 24.36 / 48%）、创业板指 2,431.20（+0.86% / +20.73 点 / 33.15 / 27%）、沪深300 4,285.63（+0.31% / +13.25 点 / 13.47 / 54%）。PE 与分位均为演示值，窗口近 10 年。

- **涨跌颜色**：严格 A 股口径，红涨 `#dc2626`、绿跌 `#16a34a`、平灰；所有涨跌数值带 `+/-` 符号；首页提供颜色图例。
- **三组颜色**：实盘 `#2563eb` / AI 影子 `#7c3aed` / 沪深300 基准 `#d97706`。趋势图沿用：历史净值蓝、今日估算蓝虚线、持仓成本橙虚线。
- **质量标记**：`official` 绿、`estimate` 琥珀、`partial` 橙、`stale` 红；每页顶栏显示数据时间与质量，页脚展示完整图例。

## 6. 只读约束

- 全站无 `<form>` / `<input>` / `<textarea>` / `<select>`；无下单、买卖、编辑实盘、写建议入口。
- 唯一的操作按钮是首页「刷新估值」（仅触发本地模拟刷新）；组合/对比页 tabs 与展开/周期切换均为只读筛选。
- 设置页开关为静态展示（`aria-hidden`、无点击行为），备份恢复入口为禁用样式。
- 页面文案明确「客户端只读」「需通过 MCP 写入口」「不构成投资建议/收益承诺」。
- token 为掩码示意，不含真实密钥。

## 7. 已知简化点

1. **无后端/接口/SSE**：所有数据来自 `assets/data.js`，不接真实行情、净值、估值、PE 或分位 API。
2. **刷新为模拟**：进入页面与手动刷新只驱动加载态与模拟时钟（每次 +47s），不请求接口、不改变种子持仓；生产环境由估值接口返回。
3. **要闻为演示文本**：标题、摘要、影响判断与来源均为主观构造的演示内容，非真实新闻，也不代表真实政策或行情。
4. **图表为内联 SVG**：未引入 ECharts 或构建链；分时与多周期序列均为确定性生成的演示数据。
5. **PE / 历史分位为演示值**：未实现真实 PE 计算或分位服务；窗口写死近 10 年，生产接口、授权与稳定性待 HOM-57 调研结论。
6. **近五年覆盖缺口**：永赢高端装备的「近五年」显示空态，模拟成立年限不足；5 只基金能否都覆盖 5 年待生产数据确认。
7. **第二条横线口径**：本轮按「持仓成本净值」实现；若用户改为前高/支撑位等其他关键位，需要返工调整。
8. **持仓口径**：为保留 P1-2 种子持仓 52.9 万 + 现金 15 万，持仓金额展示 14:30 估算快照（执行前）；14:31 的执行明细在历史页交易记录中体现。
9. **AI 影子/基准为模拟**：不计费用、不涉及真实资金。
10. **扩展仅 popup 示意**：未打包 MV3 扩展，badge/omnibox 为静态示意，无真实轮询或快捷搜索。
11. **设置不可编辑**：未实现设置写入、备份恢复、token 管理。
12. **数据时间固定**：默认演示时间为 2026-11-10 14:32:10；手动刷新仅在浏览器内递增模拟时间，刷新页面后回到固定值；展开行与趋势周期通过 sessionStorage 保持。
13. **首页行内建议为演示**：展开区复用 mock 建议字段，不代表实时决策；完整执行仍以「建议」页与 MCP 写入口为准。

## 8. 自检结果

- **截图**：7 页 × 桌面 1440px / 移动 390px = **14 张**，另扩展 popup 1 张；首页两张均含展开态、分时与多周期趋势图。
- **七档宽度**（360/390/414/768/1024/1280/1440）7 页全部 `overflowX=0`、越界元素 0、触控目标 <44px 为 0；首页展开态另做 7 档复测，无横向溢出/截断/越界。
- **首页列**：基金主列为「基金 / 当前持仓市值 / 当前权重 / 估算涨跌幅 / 今日预估收益 / 质量」，无「估算净值」「目标权重」「展开」列；桌面 1440/1280/1024 首屏可见 5 行。
- **展开控件**：位于基金名称单元格，前置 chevron 随状态旋转；鼠标、Enter/Space、Esc 均可操作；`aria-expanded` / `aria-controls` 正确；同一时间最多一行。
- **展开区**：含操作、金额、理由、执行状态、当前持仓市值、当前权重、目标权重、偏离、持仓成本；7 档宽度均渲染 2 张图（分时 + 多周期）与图例/数据表回退。
- **趋势图**：今日估算为主色虚线、持仓成本为对比色虚线，历史交叉点有圆点与细竖线；默认近一年可见交叉标记；周期切换与空态正常。

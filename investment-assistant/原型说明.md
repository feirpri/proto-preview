# 原型说明 · 7 页 PWA + Chrome 扩展 popup（v4）

> 任务：HOM-55「原型 v4：首页信息密度优化（表格化 + 建议行内展开 + 全局刷新时间）」· 2026-11-11
> 基线：HOM-40 原型 v1 / HOM-50 原型 v2 / HOM-51 原型 v3
> 版本：原型 v4 · 2026-11-11
> 定位：**只读静态原型**，用于前端开发前的视觉与交互确认；不接真实 API、不写业务数据、不包含 Phase 3 生产代码。

**查看方式**：直接双击 `index.html`，通过左侧导航（桌面）或底部导航（移动端）在 7 页之间跳转；移动端「更多」打开底部抽屉进入对比/历史/设置；扩展 popup 打开 `popup.html`。全部为本地静态文件，无需安装依赖或启动服务。

## 2. 信息架构（v4）

`首页` · `建议` · `要闻` · `组合` · `对比` · `历史` · `设置`，另保留扩展 `popup`。

- **桌面**：左侧导航列出 7 页，当前页高亮，触控/点击目标高 44px。
- **移动端**：底部导航 5 项 `首页 / 建议 / 要闻 / 组合 / 更多`；「更多」打开底部抽屉，含 `对比 / 历史 / 设置`。全部页面 ≤2 次点击可达，当前页高亮；抽屉支持遮罩点击与 Esc 关闭，条目高 54px、关闭按钮 44×44px。
- **跨页链接**：首页基金表格行内展开建议，展开区「完整明细」→ `advice.html#fund-<code>`；建议页每张卡 → 回首页；导航文案与页面 `<h1>`、顶栏标题一致。
- 与 v3 的差异：首页大盘指数与基金估值由卡片改为表格；「查看该基金建议」跳转改为行内展开/收起；刷新时间收敛为页头单点；不改变七页导航与只读约束。

## 3. 页面结构

### 3.1 首页（`index.html`）

- **页头**：标题、说明、「本次更新 HH:MM:SS」、`estimate` 质量标记、手动刷新按钮、只读标识；移动端首屏可见。全页仅此一处刷新时间；顶栏只显示数据日期，不再重复时间。
- **大盘指数表**（4 项）：上证指数、深证成指、创业板指、沪深300，列为「指数 / 点位 / 涨跌幅 / 涨跌点数 / 状态」。桌面一条一行；移动端降级为紧凑堆叠行（名称与点位一行、涨跌幅与点数一行，隐藏状态列），不横向滚动。红涨绿跌与数值口径不变。
- **基金估值表**（5 只）：列为「基金（名称 + 代码）/ 估算净值 / 估算涨跌幅 / 今日预估收益 / 目标权重 / 质量 / 建议」。
  - 桌面 1440：5 只基金在首屏内可见，数值右对齐、等宽数字、行高紧凑。
  - 移动 390：基金名占整行，估算净值/涨跌幅/今日预估收益分两列展示；目标权重与质量标签降级到基金名下方，不横向滚动。
  - `stale` 基金（通信联接）行内标注最近可用 `13:58:20` 与延迟分钟数，不冒充实时。
  - 每行「展开」按钮打开行内建议区，同一时间最多展开一行；展开区含操作、金额、理由、执行状态、当前估值与权重对比，并提供「完整明细」链接到建议页锚点。
  - 首页不再有「查看该基金建议」跳转链接；无 JS 时通过 `<noscript>` 静态快照保留核心估值数据。
- **数据口径说明**：首页唯一的 `official / estimate / partial / stale` 图例、估值/刷新口径、数据源、21:30 官方净值修正与风险提示；删除逐卡「按当前持仓估算，非官方净值」重复文案。
- **页脚**：首页不重复渲染全局页脚图例与风险声明；其他页面页脚保持原样。

### 3.2 建议（`advice.html`）

- 顶部：建议日期、整体决策摘要（市场状态「震荡」、一句话结论、目标权益仓位 72%、`executed · applied · 14:31` 状态与时间、审计保留说明）。
- 逐基金建议卡 ×5：基金名/代码、操作（保持 / 加仓 / 减仓）、金额（万元）、理由、`executed · 14:31 已应用`。
- 每卡附一行当前估值（净值 + 涨跌幅）与实际权重用于对照，标注数据时间；`stale` 基金使用最近可用时间。
- 明确「建议只读，执行仅通过 MCP 写入口」；无下单/交易按钮、无输入框。

### 3.3 要闻（`news.html`）

- 定位：可能影响经济与民生的政策、新闻与大事件；分类 `政策 / 民生 / 国际 / 行业`。
- 顶部显著标注 **「演示数据 · 非真实新闻」**，并说明「AI 每日 14:30 更新本次要闻；本页展示最近一次更新（截至 2026-11-10 14:30）的昨日/近期内容」。
- 10 条演示要闻，按时间倒序（11-10 → 11-06）；每条含日期、时间、分类、标题、1–2 句摘要、影响判断（利好/利空/中性）与受影响板块/主题、来源。
- 本期不实现刷新：无刷新按钮、无搜索/筛选交互，仅静态展示；页面注明「本期不提供刷新，后续迭代接入每日更新」。

### 3.4 组合 / 对比 / 历史 / 设置

- 更新为 7 页导航与当前页高亮，其余内容保持 v2：组合三组切换与偏离、对比三线与区间、历史时间线与交易、设置只读参数与开关展示。
- 设置页开关仍为静态示意，不响应点击；全站无写操作入口。

### 3.5 Chrome 扩展 popup（`popup.html`）

- 浏览器工具栏示意：扩展 icon + badge（显示上证涨跌幅）、omnibox `musi.local/home`。
- popup 内容：本次更新时间、4 个大盘指数（点位 + 涨跌%）、5 只基金估值摘要（净值 + 涨跌%），红涨绿跌。
- 入口：「打开首页」→ `index.html`，「查看建议」→ `advice.html`；badge/omnibox 仍仅示意。

## 4. 关键交互

| 交互 | 位置 | 行为 |
|---|---|---|
| 页面跳转 | 左侧导航 / 底部导航 | 7 页真实跳转，当前页高亮 |
| 更多抽屉 | 移动端底部「更多」 | 打开含对比/历史/设置的底部抽屉；遮罩/关闭按钮/Esc 关闭 |
| 自动刷新 | 首页进入 | 触发一次模拟刷新，按钮进入「刷新中…」态并显示加载样式，约 0.4s 后落定并显示页头「本次更新 14:32:10」 |
| 手动刷新 | 首页「刷新估值」 | 真实可点击（≥44px）；刷新中禁用并旋转图标；完成后更新页头时间（如 14:32:10 → 14:32:57），保持展开行与滚动位置，不改变布局高度 |
| 建议行内展开 | 首页基金行末「展开 / 收起」按钮 | 展开/收起该行建议；同一时间最多一行；按钮支持 Enter/Space，维护 `aria-expanded` / `aria-controls`；Esc 收起并回焦按钮 |
| 展开 → 完整明细 | 展开区「完整明细」 | 跳转 `advice.html#fund-<code>`，建议卡锚点顶部留白 |
| 建议 → 首页 | 建议卡「回首页看估值」 | 返回首页 |
| 三组切换 | 组合页 tabs | 切换实盘 / AI 影子 / 基准 |
| 区间切换 | 对比页 tabs | 切换 22 / 66 / 244 / 380 个交易日 |
| 静态要闻 | 要闻页 | 无刷新、无搜索/筛选，仅浏览 |

所有交互均为只读导航/筛选/演示刷新；除首页刷新按钮外无输入、下单、编辑、写建议入口。

## 5. 数据与视觉规范

- **种子基线**（P1-2，2026-11-05 收盘，未改动）：5 只基金；持仓 52.9 万 + 现金 15 万 = 67.9 万；目标权重 16% / 16% / 22% / 8% / 10%，合计 72%；沪深300 基准 67.9 万。
- **今日演示快照**：数据日期 2026-11-10；盘中估值时间 14:32:10（模拟）；今日预估 +3,201 元（+0.47%）；权益仓位 77.9%。
- **指数演示值**：上证 3,628.41（+0.42% / +15.21 点）、深证成指 11,452.68（+0.65% / +73.96 点）、创业板指 2,431.20（+0.86% / +20.73 点）、沪深300 4,285.63（+0.31% / +13.25 点）。
- **涨跌颜色**：严格 A 股口径，红涨 `#dc2626`、绿跌 `#16a34a`、平灰；所有涨跌数值带 `+/-` 符号；首页提供颜色图例。
- **三组颜色**：实盘 `#2563eb` / AI 影子 `#7c3aed` / 沪深300 基准 `#d97706`。
- **质量标记**：`official` 绿、`estimate` 琥珀、`partial` 橙、`stale` 红；每页顶栏显示数据时间与质量，页脚展示完整图例。
- **响应式**：360 / 390 / 414 指数与基金表均为堆叠行、无横向滚动；基金表 2 列，指数表隐藏状态列；768 平板基金表 3 列堆叠；1024+ 桌面左侧导航 + 完整表格；1280/1440 基金表 7 列、5 行首屏可见。
- **触控目标**：导航、刷新按钮、链接、抽屉条目、关闭按钮均 ≥44px。

## 6. 只读约束

- 全站无 `<form>` / `<input>` / `<textarea>` / `<select>`；无下单、买卖、编辑实盘、写建议入口。
- 唯一的操作按钮是首页「刷新估值」（仅触发本地模拟刷新）；组合/对比页 tabs 为只读筛选。
- 设置页开关为静态展示（`aria-hidden`、无点击行为），备份恢复入口为禁用样式。
- 页面文案明确「客户端只读」「需通过 MCP 写入口」「不构成投资建议/收益承诺」。
- token 为掩码示意，不含真实密钥。

## 7. 已知简化点

1. **无后端/接口/SSE**：所有数据来自 `assets/data.js`，不接真实行情、净值、估值 API。
2. **刷新为模拟**：进入页面与手动刷新只驱动加载态与模拟时钟（每次 +47s），不请求接口、不改变种子持仓；生产环境由估值接口返回。
3. **要闻为演示文本**：标题、摘要、影响判断与来源均为主观构造的演示内容，非真实新闻，也不代表真实政策或行情。
4. **图表为内联 SVG**：未引入 ECharts 或构建链；曲线为确定性生成的演示序列。
5. **持仓口径**：为保留 P1-2 种子持仓 52.9 万 + 现金 15 万，持仓金额展示 14:30 估算快照（执行前）；14:31 的执行明细在历史页交易记录中体现。
6. **AI 影子/基准为模拟**：不计费用、不涉及真实资金。
7. **扩展仅 popup 示意**：未打包 MV3 扩展，badge/omnibox 为静态示意，无真实轮询或快捷搜索。
8. **设置不可编辑**：未实现设置写入、备份恢复、token 管理。
9. **要闻不刷新**：按要求本期无刷新、无搜索/筛选；后续迭代接入每日 14:30 更新。
10. **数据时间固定**：默认演示时间为 2026-11-10 14:32:10；手动刷新仅在浏览器内递增模拟时间，刷新页面后回到固定值。
11. **首页行内建议为演示**：展开区复用 mock 建议字段，不代表实时决策；完整执行仍以「建议」页与 MCP 写入口为准。

## 8. 自检结果

- **截图**：7 页 × 桌面 1440px / 移动 390px = **14 张**，另扩展 popup 1 张（见 `screenshots/`）。
- **七档宽度**（360/390/414/768/1024/1280/1440）7 页全部 `overflowX=0`、`clipped=0`、越界元素 0、触控目标 <44px 为 0（见 `screenshots/audit.json`）。
- **首页**：大盘指数与基金估值为表格；4 个指数均含点位 + 涨跌幅 + 涨跌点数 + 状态；5 只基金均含估算净值 + 涨跌幅 + 今日预估收益，桌面 1440/1280/1024 首屏可见 5 行；`stale` 1 只并在行内显示最近可用时间与延迟。
- **刷新**：打开页面自动进入模拟刷新；手动刷新按钮 99×44px（移动）/ 103×44px（桌面），刷新中禁用并显示「刷新中…」，完成后全页唯一时间更新（14:32:10 → 14:32:57），展开行与滚动位置保持。
- **行内建议**：鼠标点击行末「展开 / 收起」按钮、键盘 Enter/Space 均可展开/收起；`aria-expanded` 正确，同一时间最多展开一行；展开区含操作、金额、理由、执行状态、当前估值/权重对比。
- **导航**：桌面 7 项；移动底部 5 项（4 页 + 更多）；「更多」抽屉 3 项，条目 56px、关闭按钮 44×44px，Esc 可关闭；所有页面当前页高亮。
- **建议页**：5 张建议卡锚点 `fund-006503` / `fund-018345` / `fund-006864` / `fund-007818` / `fund-015790` 与首页展开区「完整明细」链接一一对应；无输入/交易控件。
- **要闻页**：10 条、4 类、时间倒序；含「演示数据 · 非真实新闻」与「AI 每日 14:30 更新、本期不刷新」说明；无刷新/筛选控件。
- **只读**：全站 input/textarea/select/form = 0；交易类按钮 = 0；设置开关为静态展示。

## 9. 确认门

原型 v4 用于用户对首页信息密度改版进行视觉与交互确认。**用户提出优化不等于已确认原型 v4；原型确认门与 Phase 3 启动门不变**；如继续提出改版，按新任务返工处理。

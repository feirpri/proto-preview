## 2. v8 的目标与取舍

1. **只保留一张基金表**：v7 的只读「基金持仓」与「实盘数据编辑」合并为「我的基金」。
2. **一行只放决策需要的两个数**：当前持仓金额、今日涨跌（金额 + 幅度）。
3. **编辑主要是改金额**：行尾编辑图标进入弹层，只改金额与生效时间；删除收进编辑弹层并二次确认。
4. **金额是主输入**：份额、单位成本、净值、权重、目标权重、现金、总资产都不再出现在首页。
5. **金额之和内部计算**：系统内部按各基金当前金额汇总，首页不显示、不可编辑。
6. **不做跨记录重算**：历史生效时间只提示「有更晚记录，当前持仓仍以最新记录为准」，不回溯重算后续，避免 v7 的负现金/超 100% 路径。

## 3. 首页信息架构

从上到下：

1. 顶栏：本次更新时间、刷新估值、token 退出。
2. 显著提示：`演示写入 · 仅保存在本地，不影响实盘`；`原型模拟门禁，真实 token 由服务端生成`。
3. 大盘指数：点位 / 涨跌幅 / PE-TTM / PE 历史分位（演示）。
4. **我的基金**：唯一基金表 + 「添加基金」按钮。
5. **最近操作**（默认折叠）：时间 / 类型 / 基金 / 前 → 后 / 来源；撤销上一笔、恢复演示初始值。
6. 数据口径说明。

## 4. 我的基金（唯一基金表）

表头：`基金` | `当前持仓`（右对齐） | `今日涨跌`（右对齐） | 操作图标（无文字表头）。

每只基金恰好一行：

- 左：基金名称（按钮，点击打开详情弹层）+ 基金代码小字。
- 中：当前持仓金额，右对齐、等宽数字、单行。
- 右：今日涨跌金额 + 幅度，例如 `+¥1,189 / +0.82%`，红涨绿跌、单行、右对齐。
- 行尾：编辑图标按钮 44×44px，`aria-label="编辑 <基金名>"`。

不显示：份额、单位成本、净值、权重、目标权重、现金、总资产、持仓合计。

移动端（≤900px）使用三列网格：名称/金额第一行、涨跌第二行、编辑图标跨两行靠右；仍保持每只基金一个列表行。

## 5. 编辑弹层（已有基金）

标题 `编辑 · <基金名>`。字段只有：

1. 当前持仓金额（只读）。
2. 修改后持仓金额（必填、自动聚焦、≥0、最多 2 位小数）。
3. 生效时间（日期 + 时间，默认现在）。

实时摘要：`加仓 +¥2,000` / `减仓 −¥2,000` / `清仓` / `保持`，以及 `持仓金额 前 → 后`、`变动`、`生效时间`。

删除基金：弹层底部 danger 按钮 → 二次确认「确认删除该基金记录？」→ 确认后从列表移除并写审计；可「返回编辑」。

保存：写入 `localStorage`，刷新行与审计，显示成功提示，可撤销。

校验：金额非负、最多 2 位小数、生效时间有效；非法时就地提示并禁用保存。若该基金有更晚记录，只提示「当前持仓仍以最新记录为准，不重算历史」。

## 6. 添加基金弹层

字段：基金代码（6 位、去重）、基金名称（非空）、首次持仓金额（≥0、两位小数）、生效时间。

无份额、净值、成本、权重字段。

## 7. 基金详情弹层

点击基金名称打开，保留：

- 当前持仓金额、今日涨跌。
- 今日建议（操作、建议金额、原因）。
- 当日分时 + 多周期趋势图；放大 / 缩放 / 平移 / Esc 关闭 / 焦点返回。
- `015790` 五年档「成立以来」。
- 不提供目标权重或份额编辑入口。

## 8. 最近操作与本地审计

默认折叠的 `<details>`，展开后：

- 汇总：本地操作条数、来源「网页」、撤销上一笔、恢复演示初始值。
- 列：时间 / 类型 / 基金 / 前 → 后 / 来源。
- 撤销上一笔按最后写入顺序移除；恢复初始值清空操作并回到演示初始金额。

## 9. 数据与存储口径

- 每只基金维护：代码、名称、当前持仓金额、今日估算涨跌幅（演示）、操作历史（生效时间、操作前金额、操作后金额）。
- 当前持仓金额 = 该基金最新一条操作金额；无操作时用演示初始值。
- 各基金金额之和仅在内部计算，不展示、不可编辑。
- 编辑 = 单基金金额快照修正，不改其他基金。
- 存储键：操作 `musi.v8.ops`；图表周期/滚动 `musi.v8.ui`；token `musi.auth.token`。
- v7 的 `musi.v7.ops` / `musi.v7.ui` 不再读取，避免旧份额/现金操作带入非法状态。

## 10. Token 门禁

- 无 token、错误 token：只显示输入页，信息页不渲染。
- 正确 token `demo-2026`：写入 `localStorage` 后进入。
- 退出：清除 token 并重新拦截。
- 直达任意 HTML URL 同样拦截。
- 原型门禁不构成真实安全边界；真实 token 由服务端生成。

## 11. 响应式与可访问性

- 360 / 390 / 414 / 768 / 1024 / 1280 / 1440 七档无横向溢出、无裁切。
- 所有可交互目标 ≥44×44px；编辑图标与添加按钮均满足。
- 名称按钮、编辑按钮均有 `aria-label`；弹层使用 `role="dialog"`、`aria-modal`，Esc 关闭并返回触发元素焦点。
- 金额与涨跌使用 `font-variant-numeric: tabular-nums`，单行不换行。

## 12. 自检结果（v8 audit.json）

- 7 页 × 7 档宽度：横向溢出 0、裁切 0、触控 <44px 0。
- 门禁：无 token 仅输入页；错误 token 拒绝；`demo-2026` 进入；退出后重新拦截。
- 首页：只有一张基金表、5 行、每行 4 个单元格、无份额/净值/成本/权重/现金/总额文本。
- 编辑：3 个字段（current / amount / time）、金额两位小数与负数校验、实时前→后摘要。
- 历史时间：显示「有更晚记录」提示；保存早于历史后当前金额仍取最新记录。
- 删除：仅编辑弹层内，二次确认，可返回编辑；删除后行消失并写审计。
- 详情：2 张图表、2 个放大入口、无目标权重编辑；`015790` 成立以来；Esc 焦点返回。
- 撤销 / 恢复初始值：操作记录与金额同步恢复。

## 13. 已知简化点

- 所有数据与走势为演示构造，生产数据接口与授权待调研确认。
- 今日涨跌按演示估算幅度 × 当前金额计算，不代表真实收益。
- 新增基金的走势为演示生成序列，不代表真实历史。
- 生效时间仅作为单基金记录时间；不执行跨记录/跨基金重算。
- 本地写入仅用于确认交互，不构成账本、审计链或交易能力。

## 14. 确认门

原型 v8 仅用于用户对「单行基金列表 + 金额编辑」进行视觉与交互确认。**用户提出优化不等于已确认原型；原型确认门与 Phase 3 启动门仍关闭。** 演示 token 与本地写入不代表已接入真实鉴权、写接口或实盘账本。
